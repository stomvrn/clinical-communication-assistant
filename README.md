## Что это

Инструмент для врачей, которые хотят системно подходить к разговору с пациентом — не «интуитивно», а с опорой на структуру.

Это не книга и не методическое пособие. Это интерактивный чек-лист, который открывается в браузере и работает прямо во время приёма.

**Внутри:**

- **102 навыка**, сгруппированных в **15 этапов** клинического взаимодействия
- **60 базовых** и **42 расширенных** навыка
- К каждому навыку — два блока пояснений: **«Зачем»** (обоснование) и **«Связь»** (взаимодействие с другими этапами)
- Прогресс сохраняется автоматически
- Экспорт в CSV для интеграции с внешними системами
- Seed IR — криптографический идентификатор сессии на базе SHA-256
- Печатная версия (Ctrl+P)

**Работает без интернета. Данные не покидают устройство.**
